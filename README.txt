FUTURE COMPUTER CENTRE - EXAM SYSTEM

How to use:
1. Open index.html in Google Chrome or Microsoft Edge.
2. Enter student details and start the 30-question, 60-minute exam.
3. Passing percentage is 40%.
4. After submission, a passing student can click Generate Certificate.
5. In the certificate window, click Print / Save as PDF.

Important:
- This is an offline browser-based system; no internet or server is required.
- Results are stored in the browser's localStorage on that computer.
- For official/recognized certification, use only claims your centre is legally authorized to make.
- You can replace questions, logo, signature, and design later.
